# @ticket-system/web

This is the Web Frontend for the Ticket System.

## Development

- Mind that this project relies on the Server Application.
- To reach it you have to run the docker/localReady.sh script in this or the root directory.
- Then run:

```bash
npm install
npm run dev
```

- The Web Frontend will be served on port 4200.

## Production

- Please just use the documentation provided in the [README](../../README.md) of the root directory.
